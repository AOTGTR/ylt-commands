# ylt-commands

เว็บรวมคำสั่งเกมต่อตึก (YL Tower) สำหรับสตรีมเมอร์

**เปิดดู:** https://aotgtr.github.io/ylt-commands/

- ลิงก์โอเวอเลย์ OBS อยู่บนสุด กดคัดลอกได้
- ส่งชนะ/ส่งแพ้ อยู่บนสุดของรายการคำสั่ง
- แยกหมวด ช่วย / แกล้ง / อื่นๆ · ค้นหาได้ทั้งชื่อคำสั่งและคำอธิบายไทย
- กด `Tab` เติมคำสั่งอัตโนมัติ · คลิกคำสั่งเพื่อคัดลอก · กด `/` ไปที่ช่องค้นหา
- ล่างสุดมีรายการแบบข้อความล้วน กดปุ่มเดียวคัดลอกทั้งหมด เอาไปวางในแชท/ดิสคอร์ดได้

หน้าเดียว ไม่มี dependency — `index.html` ไฟล์เดียว ธีมมืดอย่างเดียว
